# Report writing guide

Replace these prompts with footage-specific observations before rendering. This is an optional structure, not a completed diagnosis.

## Player context and review scope

Describe experience, concerns, camera view and selected windows. Separate extracted counts from actual manual coverage. Identify montage bias and missing opponent/landing views where relevant.

## Priorities grounded in evidence

For each priority give video time, evidence IDs, visible change, interpretation and a testable practice adjustment. Preserve useful movements. Consider preparation, spacing/footwork, contact, follow-through and recovery continuously.

## Practice plan

Offer a manageable progression: one cue, controlled feeding, an outcome measure, then variation. Explain how to test the player's reported problem without claiming an unobserved cause.

## Key windows and limitations

Link representative evidence and source playback. Distinguish uncertain contact, out-of-frame recovery, camera limits and unreviewed portions. Attribute external coaching guidance near the relevant advice.
